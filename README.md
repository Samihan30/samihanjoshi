# Samihan Video Editor Portfolio

A responsive, cinematic static portfolio built with HTML, CSS and JavaScript.

## Folder structure

```text
samihan-video-editor-portfolio/
├── index.html
├── style.css
├── script.js
├── .nojekyll
├── 404.html
├── README.md
├── assets/
│   └── logo.png
├── images/
│   └── (add project thumbnails here)
└── videos/
    └── showreel.mp4   <-- add your real showreel
```

## Before publishing

Open `index.html` and replace:

1. `YOUR_EMAIL@example.com` with your real email.
2. `https://www.instagram.com/` with your Instagram URL.
3. The placeholder project names/descriptions with your real work.
4. `videos/showreel.mp4` with your actual showreel.
5. Add project thumbnails/videos if you want to turn the project cards into real media.

## Local preview

Recommended:
- Open the folder in VS Code.
- Install Microsoft's "Live Preview" extension.
- Open `index.html`.
- Start the preview.

You can also open `index.html` directly in Chrome.

## Deploy with GitHub Pages

1. Create a GitHub repository.
2. Upload all files and folders from this project.
3. Make sure `index.html` is in the repository root.
4. Go to Settings → Pages.
5. Under Build and deployment, select "Deploy from a branch".
6. Select `main` and `/ (root)`.
7. Save.
8. Wait for GitHub Pages to publish the site.

Do not upload private client footage, confidential files, passwords, API keys or other sensitive material to a public repository.

## Important

This is a static site, so the contact button uses email. If you want a real contact form that stores submissions, connect it later to a form service or backend.
